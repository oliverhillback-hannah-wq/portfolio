Portfolio – från skiss till kod
1. Från skiss till kod

Jag utgick från Pawans design i Figma och byggde sidorna med HTML och CSS. Det svåraste var att få layouten att se bra ut på både mobil och dator. Jag löste det med media queries.

2. Semantik

Jag använde header, nav, main, section och footer för att strukturera sidan. Jag använde div när jag behövde gruppera element för styling.

3. Layout

Jag använde Flexbox för att placera innehåll och media queries för responsiv design. Vid 768 pixlar ändras layouten för större skärmar. Jag använde främst Flexbox eftersom det passade min design.

4. Tillgänglighet

Jag använde tydliga rubriker, semantisk HTML och labels till formulärfälten. Jag behöver testa sidan mer med tangentbord och kontrollera färgkontrast och fokusmarkeringar.

5. Användbarhet

Pawans design har tydlig navigering, konsekventa färger och bra avstånd mellan elementen. Jag skulle göra länkarna ännu tydligare och kontrollera att sidan är enkel att använda på mobil.

6. Styrkor och brister

Jag tycker att det är bra att sidan är uppdelad i flera sidor och att HTML och CSS är separerade. Med mer tid skulle jag förbättra tillgängligheten, testa fler skärmstorlekar och göra kontaktformuläret fungerande.

7. AI-verktyg

Jag använde AI för att få hjälp med HTML, CSS och problem med layouten. Jag ändrade förslagen så att de passade min webbplats och kontrollerade att ändringarna fungerade.
